### Сущности:
1) User - interface - родитель дочерних Reader и Librarian. Пользователь системы для библиотеки
2) Reader - сущность читателя, который посещает библиотеку. Имеет список арендованных книг, список штрафов, список книг
3) Librarian - сущность библиотекаря, который выдает книги, проводит аренду и оформляет штрафы
4) Rent - сущность аренды, имеет в себе свойства аренды
5) Penalty - сущность штрафа, имеет в себе свойства штрафа за просрочку возврата книги
6) Library - сущность библиотеки, позволяет взять книгу по id книги или по id автора
7) Book - сущность книги
8) Author - сущность автора
